## 📖 專案簡介 (About The Project)

**復古學院黑板風英文單字卡** 是一款專為全家共學、大考衝刺（學測／會考／多益／托福／GRE）及自主精進打造的**純前端輕量化單字學習系統**。

本系統採用經典深綠色黑板視覺風格，搭配手寫粉筆微浮雕質感與護眼色調，完全擺脫死背字典的枯燥感。系統內建 **36,000 龐大深度字庫**，全面摒棄模板化重複例句，全數採用生活真實日常例句與權威大考語料；更首創**「真・字首字根字尾 邏輯記憶體系」**，讓學習者能像滾雪球般，透過小零件的邏輯推導一口氣掌握一整群高階單字！

## 🌟 核心特色 (Key Features)

### 1. 🧩 真・字首、字根、字尾 邏輯記憶法體系 (Etymology System)
* **三大核心概念拆解**：
  * **字首（Prefix）**：改變單字方向、意義或否定（如 `im-` 向內、`ex-` 向外、`re-` 再次）。
  * **字根（Root）**：單字核心實質意義，如同中文部首（如 `port` 運送、`spect` 觀看、`ject` 投擲）。
  * **字尾（Suffix）**：決定單字詞性與形態（如 `-able` 形容詞、`-tion` 名詞、`-ize` 動詞）。
* **三步驟拆解示範**：遇到長難單字時「拆解 ➔ 理解 ➔ 重組」（以 `immemorial` 為標竿範例：`im-` 不 + `memor` 記憶 + `-ial` 形容詞 ➔ *無法追憶的、遠古的*）。
* **同字根滾雪球家族（Word Families）**：收錄 55+ 古典拉丁與希臘字根，卡片背面自動展示彩色拆解公式膠囊與同族詞清單，各單字均可獨立點擊朗讀。
* **拒絕無效拼湊**：徹底剔除傳統「前兩個字母相同」的無效拼湊雜訊，基礎生活詞（如 `chair`, `banana`）保持簡潔乾淨。
* **🎓 內建「字根字首指南」教學視窗**：隨時點擊頂部按鈕，查閱完整拆解心法與大考實戰猜詞技巧。

### 3. 🧠 艾賓浩斯記憶評估 ＋ 即時拼寫防呆機制
* **三段式掌握度即時標記**：
  * 🟢 **非常熟悉**：單字直接納入熟記庫，掌握度進度條即時推進。
  * 🟠 **不熟／忘了**：自動保留於複習佇列，稍後循環再次考驗。
  * 🔴 **完全陌生**：立即啟動防呆記憶強化。
* **即時引導拼寫互動框**：若點選「不熟」或「陌生」，系統立即跳出遮蔽字母格，要求學習者親手鍵入拼寫，徹底擊碎「看過以為記住」的假性記憶盲點。

---

### 4. 🎴 雙重視圖切換 ＋ 自由練習量選擇
* **批次卡片抽取**：可自訂每次抽卡練習數量（**10、20、30、50、100 張或全部**），並支援「🔀 隨機換批」，徹底擺脫死板的字母順序背誦。
* **📖 字典速查模式**：即時秒搜全庫 36,000 單字，邊打字邊過濾，點擊即可翻閱完整發音、例句與字根拆解。

---

### 5. 🔊 發音、觸控手勢與極致跨平台體驗
* **Web Speech 雙速自然朗讀**：單字發音、道地例句朗讀、俚語片語朗讀、同族詞獨立發音，全方位訓練英聽口說。
* **手機手勢滑動**：支援左右滑動切換卡片、輕觸翻面，操作如原生 App 般流暢自然。
* **離線即開即用（PWA 優化）**：初次載入後瀏覽器自動快取，日後即使無網路環境也能隨時隨地開啟複習。
* **資料庫大幅減重（僅 14.47 MB）**：代碼與資料庫高度最佳化，下載速度大幅提升 40%，且內建版本快取防呆機制（Cache Busting）。

---

### 6. 🔐 100% 隱私安全・零伺服器依賴
* **純本機 LocalStorage 儲存**：學習紀錄（熟記單字清單、自訂卡片）100% 保留在使用者個人的手機或電腦瀏覽器中，不經由任何外部伺服器，零個資外洩風險。
* **一鍵資料備份與還原**：點擊右上角「💾」圖示，即可隨時將個人的學習進度匯出為 JSON 備份檔，更換手機或電腦時可無痛匯入還原。

## 📱 手機使用推薦：加入主畫面 (Add to Home Screen)

若想在手機上享有如獨立 App 般的**全螢幕體驗（隱藏網址列）**，請依以下方式操作：

### 🍎 iPhone / iPad (Safari)
1. 使用 Safari 開啟 [線上網址](https://aletheia-h.github.io/English-Vocab/)。
2. 點擊瀏覽器底部的 **「分享 📤」** 按鈕。
3. 向下滑動並選擇 **「加入主畫面 ➕」**。
4. 返回手機桌面，即可點擊專屬圖示進入全螢幕黑板介面！

### 🤖 Android / Pixel 8 Pro / Samsung (Chrome)
1. 使用 Chrome 開啟 [線上網址](https://aletheia-h.github.io/English-Vocab/)。
2. 點擊右上角選單 **「⋮」**。
3. 點選 **「新增至主螢幕」** 或 **「安裝應用程式」**。
4. 即可在手機桌面點擊圖示，以原生 PWA 全螢幕秒速啟動！

## 🛠️ 本地開發與自架說明 (Local Setup)

本專案為純靜態網頁（Static Web App），無需安裝 Node.js、編譯工具或資料庫伺服器：

1. **複製本儲存庫**：
   ```bash
   git clone https://github.com/Aletheia-H/English-Vocab.git
   ```
2. **直接開啟**：
   * 雙擊資料夾內的 `index.html` 即可在任一瀏覽器中開啟使用。
3. **或使用輕量 Python 伺服器啟動**：
   ```bash
   python -m http.server 8080
   ```
   在瀏覽器開啟 `http://localhost:8080` 即可體驗。
