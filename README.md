# 復古學院黑板風・全方位英文單字卡學習系統
*(Chalkboard Academic Vocabulary Web App)*

專為全家共學與自主進修打造的現代化 HTML 單字卡學習網頁，支援手機觸控、離線使用與個人設備獨立儲存。

---

## 🌟 六大專業學習通道（全庫共 36,000 單字）

1. **🎒 國中會考 2000 單 (`junior_2000`)**：2,000 單。日常生活、會考高頻單字、KK 音標、生活實用短句。
2. **🏫 高中關鍵 7000 單 (`senior_7000`)**：7,000 單。學測分科必備、溫故知新、詞性辨析與衍生同反義詞。
3. **📕 托福學術進階 (`toefl`)**：10,000 單。留學檢定與學術論文閱讀高頻字彙、學術長難句與同義替換。
4. **💼 職場商務與多益 (`business`)**：5,000 單。國際商務溝通、會議談判、合約專案、金融外貿與多益核心高頻商用詞彙。
5. **🎓 GRE 頂尖學術思辨 (`gre`)**：2,000 單。高階學術思辨、精準微差辨析、希臘與拉丁字根字首記憶心法。
6. **☕ 專欄閱讀與日常會話 (`reading_daily`)**：10,000 單。當代美語語料庫（COCA）、Medium 專欄、外媒深度長句與地道口說表達。

## 📱 手機與電腦使用方式

### 方式 1：電腦直接點開
直接用檔案總管雙擊 [`index.html`](file:///c:/Users/peggy/Documents/antigravity/adventurous-galileo/index.html)，任何瀏覽器（Chrome、Edge、Safari、Firefox）皆可立即離線使用！

### 方式 2：手機同 Wi-Fi 區域網路瀏覽（免傳檔）
目前電腦已在背景啟動 Python 本地伺服器（Port 8080）：
- 手機連接家中相同 Wi-Fi 後，在手機瀏覽器輸入：
  - `http://192.168.68.104:8080/` 或 `http://192.168.11.4:8080/`
- **加入主畫面技巧**：
  - iPhone (Safari)：點擊底部「分享」按鈕 ➔ 選擇「加入主畫面」。
  - Android (Chrome)：點擊右上角「⋮」選單 ➔ 選擇「新增至主螢幕」。
  - 即可像原生 App 一樣以全螢幕流暢運行！

### 方式 3：分享給親友或部署到雲端
將本資料夾內的檔案（`index.html`, `style.css`, `app.js`, `data.js`）直接上傳至 **GitHub Pages**、**Vercel** 或 **Netlify**，即可產生一個永久網址，隨時分享給任何人！

## 🔐 隱私與設備獨立儲存說明

- **本機 LocalStorage**：背過的單字進度、待複習隊列、個人自訂單字百分之百儲存在每個人的手機或電腦中，完全不經由伺服器，零個資風險。
- **多人分享獨立**：分享給家人或朋友時，每個人的手機都有自己獨立的進度，互不干擾。
- **一鍵備份/還原**：點擊右上角「💾 儲存」圖示，即可將個人進度匯出成 JSON 檔案，更換手機隨時匯入！
