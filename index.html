📖 高效單字擴充術

字首・字根・字尾 邏輯記憶法指南

字首、字根、字尾記憶法是一種將英文單字拆解成小零件、透過邏輯推導來快速擴增字彙量的高效學習方式。只要掌握核心零件，就能像滾雪球般輕鬆記住一整群單字！

🌟 三大核心概念（Core Concepts）

字首 Prefix 放在最前方
主要用來改變單字的意思、方向、否定或程度。
例：im- (向內), ex- (向外), un- (否定)
字根 Root 核心主體（如部首）
單字的根本核心，帶有最主要的實質本質意義。
例：port (運送), spect (觀看), ject (投擲)
字尾 Suffix 放在最後方
主要用來決定單字的詞性與形態。
例：-able (形容詞), -tion (名詞), -ize (動詞)

⚡ 三步驟拆解法（Step-by-Step Breakdown）

範例單字：immemorial [ˌɪməˈmɔːriəl]
Step 1
① 拆解零件
找出頭身尾：
im- + memor + -ial
Step 2
② 理解涵義
分別對照意義：
• im- ＝ 否定／無
• memor ＝ 記憶
• -ial ＝ 具…特性的 (adj.)
Step 3
③ 邏輯重組
串聯整合意義：
「不 ＋ 記憶 ＋ 具有特性」
➔ 無法追憶的、遠古的

🚢 經典字根滾雪球家族演練（Word Families）

字根 port ＝ 拿、帶、運送 (Latin portare)
import 🔊 im- (向內) ＋ port (運送) ＝ 輸入、進口
export 🔊 ex- (向外) ＋ port (運送) ＝ 輸出、出口
portable 🔊 port (運送) ＋ -able (可…的) ＝ 便攜的、可隨身攜帶的
transport 🔊 trans- (跨越) ＋ port (運送) ＝ 運輸、交通運送
report 🔊 re- (回頭) ＋ port (帶回) ＝ 把消息帶回、報告
support 🔊 sub- (在下方) ＋ port (承載) ＝ 從下方支撐、支持
字根 spect ＝ 看、視察 (Latin specere)
inspect 🔊 in- (深入內部) ＋ spect (看) ＝ 深入細看、檢查視察
expect 🔊 ex- (向外) ＋ spect (看) ＝ 向前張望、期待預期
respect 🔊 re- (回頭) ＋ spect (看) ＝ 令人回頭再看、尊敬重視
prospect 🔊 pro- (向前) ＋ spect (看) ＝ 向前看的前景、展望
retrospect 🔊 retro- (向後) ＋ spect (看) ＝ 回顧往昔、回想
字根 ject ＝ 投、擲、拋出 (Latin jacere)
reject 🔊 re- (退回) ＋ ject (丟) ＝ 往回丟棄、拒絕
inject 🔊 in- (入) ＋ ject (推入) ＝ 注射、注入
project 🔊 pro- (向前) ＋ ject (投擲) ＝ 向前投射光影、企劃項目
eject 🔊 e- (出) ＋ ject (丟) ＝ 逐出、彈射出來

🎯 大考實戰應用（多益 / 學測 / 托福 GRE）

• 遇到從沒背過的長難字時：先冷靜用「三步驟拆解法」尋找字首與字尾，剝除修飾成分後找出核心字根，即使不知道確切中文，也能百分之百推導出詞性與正負褒貶方向！

• 字卡即時聯動：在翻開任何具備詞源的單字卡背面時，系統會自動標示該字的零件公式與同字根家族，點擊喇叭即可立即同步聽音練發音。
